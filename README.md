# Lucky Clover

Бот регистрации гильдии Lucky Clover. Человек нажимает кнопку в канале регистрации, выбирает класс и роль, пишет имя персонажа. Бот одним запросом ставит ник и выдаёт роли класса, `Tank` / `Heal` / `DPS` и `Initiate`.

Процесс без базы, без голоса и без кэша участников. На Linux при старте через `start.sh` рабочий расход обычно 40–70 МБ.

## Роли

Имена должны совпадать точно, включая регистр:

`Initiate`, `Tank`, `Heal`, `DPS`, `Warrior`, `Paladin`, `Hunter`, `Rogue`, `Priest`, `Shaman`, `Mage`, `Warlock`, `Druid`.

Роль бота стоит в списке ролей выше всех этих ролей. Бот роли не создаёт.

В анкете подписи по-русски: Воин, Танк, Хил, ДД. На сервер уходят английские имена ролей.

Повторная анкета снимает прежний класс и прежнюю роль Tank/Heal/DPS, остальные роли не трогает. `Initiate` остаётся.

Ник: 2–32 символа, буквы, пробел, дефис и апостроф. Подойдёт `Arthas` и `Arthas Menethil`. Ник владельца сервера Discord не меняется, роли ему всё равно выдаются.

## Бот в Discord

1. Открой [Discord Developer Portal](https://discord.com/developers/applications) и создай приложение.
2. Вкладка Bot: скопируй токен. Privileged intents не включай: ни Server Members, ни Message Content, ни Presence.
3. Включи режим разработчика в Discord (Настройки → Расширенные → Режим разработчика). ПКМ по серверу, каналу регистрации и скопируй ID.
4. Пригласи бота. Подставь ID приложения вместо `CLIENT_ID`:

```
https://discord.com/oauth2/authorize?client_id=CLIENT_ID&scope=bot%20applications.commands&permissions=402746384
```

Эти права: Manage Channels, View Channel, Send Messages, Manage Messages, Embed Links, Read Message History, Manage Nicknames, Manage Roles.

## Настройка сервера

1. Создай роли из списка выше.
2. Подними роль бота над ними.
3. Создай текстовый канал регистрации.
4. Выдай `Initiate` всем, кто уже должен видеть сервер. После `/reg-lock` человек без `Initiate` и без права администратора увидит только регистрацию.
5. Скопируй `.env.example` в `.env` и впиши токен, ID сервера и ID канала. `.env` никому не отправляй и в архив он не входит.

```
DISCORD_TOKEN=...
GUILD_ID=...
REG_CHANNEL_ID=...
```

6. Запусти бота и дождись в логе строки `synced 2 commands`.
7. На сервере, в канале регистрации, выполни `/reg-panel`. Команда для администратора. Она публикует или обновляет анкету и закрепляет её.
8. Когда текущий состав уже с `Initiate`, выполни `/reg-lock` и подтверди.

`/reg-lock` делает так:

- канал регистрации виден `@everyone`, писать в нём нельзя;
- остальные каналы от `@everyone` скрыты и открыты для `Initiate`;
- канал регистрации для `Initiate` скрыт;
- роль бота получает просмотр каналов, чтобы бот сам себя не закрыл.

Администратор по-прежнему видит все каналы. У офицера без права администратора регистрация тоже скроется, если на нём есть `Initiate`. Штабные каналы команда тоже откроет роли `Initiate`: после неё сними просмотр вручную там, куда новобранцам нельзя.

Пока бот запущен, новый человек видит только регистрацию, жмёт «Зарегистрироваться» и после анкеты получает доступ к остальному серверу.

## Запуск

Нужен Python 3.10 или новее. Голосовые зависимости не ставь.

```
pip install -r requirements.txt
```

Linux, в том числе бесплатный хостинг:

```
sh start.sh
```

`start.sh` включает `MALLOC_ARENA_MAX=2`. Без этого glibc раздувает маленький процесс Python и упирается в 100 МБ.

Та же команда без скрипта:

```
MALLOC_ARENA_MAX=2 PYTHONDONTWRITEBYTECODE=1 PYTHONUNBUFFERED=1 python3 bot.py
```

Windows для проверки:

```
python bot.py
```

Хостинг должен держать процесс включённым. Бот не открывает порт: он сам подключается к Discord. Если площадка гасит всё, что не слушает HTTP, она этому боту не подходит.

В логе нехватка роли выглядит так: `missing role: Mage`.

## Архив

`lucky-clover-bot.zip` лежит в корне проекта. Внутри:

- `bot.py`
- `requirements.txt`
- `start.sh`
- `.env.example`
- `README.md`

На хостинге распакуй архив, создай `.env` по примеру, поставь зависимости и запусти `start.sh`.
